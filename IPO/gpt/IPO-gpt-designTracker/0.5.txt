D. PITFALLS / CAVEATS RECORDED
--------------------------------------------------------------------------------
  D1. Single reference PNG, single lighting condition.
      All 7 samples come from one frame. Real gameplay includes lamp
      glare, shadows near rails, and exposure drift across clips.
      Mitigation already in the plan: F3 widening (+-5 / +-10 / +-10)
      plus the fact that 4.1 computes white_ratio on the ROI, which is
      area-invariant to overall lighting shifts.
      Watch: if dev 3.1 shows cloth under-masked in clips 3 or 5, widen
      V_HI (currently 166) toward 180 and re-verify.

  D2. Tight S lower bound (243).
      Cloth saturation is >253 in the reference. Lower bound 243 is a
      10-unit margin. In glare, saturation drops toward 0 (white). If
      a glinted patch of cloth reads as S < 243, the cloth mask will
      fail locally. Expect the ball mask to show a cloth-coloured rim
      around very bright balls; this does not violate the pipeline but
      would enlarge the ball contour. Fallback in dev 3.4: the
      circularity filter drops elongated artefacts.

  D3. Header-guard order bug — RESOLVED in this step.
      0.4 D3 reported DATA_ROOT appearing before #pragma once.
      config.h now has #pragma once as the first token.
      Verification: reading config.h top-down, line 1 is #pragma once.
      No ODR violation risk; MinGW behaviour no longer relied upon.

  D4. Comments must avoid forbidden tokens.
      0.4 D2 required lexical discipline. In 0.5, section headers such as
      "// --- Contour filter (3.4) ---" were written without any banned
      substring. Verified by C4 (SCOPE OK).

  D5. Python imports Pylance warnings.
      Editor reported reportMissingImports for cv2 and numpy inside
      VS Code. Root cause: the Python language server was pointed at the
      wrong interpreter, not at a missing package. The script executed
      correctly under C:\dev\envs\IAI-env, which confirms cv2 and numpy
      are installed.
      Resolution (editor-level only): Ctrl+Shift+P -> "Python: Select
      Interpreter" -> C:\dev\envs\IAI-env\Scripts\python.exe.
      No source change required. Pylance underlines are cosmetic and do
      not affect runtime or the C++ build.

  D6. Sampler file lives under src/.
      0.4 D4 decided no scripts/ folder. cloth_sampler.py is placed next
      to config.h to keep the tree minimal. It is .py, so
      scope_check.ps1 (-Include *.cpp,*.h,*.hpp) does not scan it.
      Future Python utilities should follow the same placement and the
      same "calibration-only, not in build" contract.

  D7. No magic-number enforcement in scope_check.ps1.
      The script checks for scope violations, not numeric literals. The
      "no magic numbers in main.cpp" rule from designTracker 0.5 is
      enforced by code review at commit time. If a stricter check is
      wanted later, an additional pattern can be added to a separate
      script; do not conflate it with scope enforcement.
