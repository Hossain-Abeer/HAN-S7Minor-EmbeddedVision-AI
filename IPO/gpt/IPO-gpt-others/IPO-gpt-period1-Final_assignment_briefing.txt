2. EVD1 ASSESSMENT CRITERIA & RUBRIC
--------------------------------------------------------------------------------
- The final assignment is standalone. Exercises are practice, not mandatory submissions.
- The module demands a 5-step OpenCV vision pipeline:
  1. Acquisition (VideoCapture or imread)
  2. Enhancement (Background subtraction, warp, blur, etc.)
  3. Segmentation (Thresholding, inRange, findContours)
  4. Feature Extraction (At least 2 techniques: Canny, Sobel, Color processing, Morphology)
  5. Classification (Blob analysis, Template matching, no Deep Learning required here)
- Grading: 36 points total. 
- "Knockout" Rule: The student must convincingly explain the design and code 
  choices. Failing this fails the assignment regardless of code functionality.

3. EVD1 SCOPE & COMPLEXITY
--------------------------------------------------------------------------------
- EVD1 Application: Build a real-time C++ pipeline that classifies billiard 
  balls into Solid, Stripe, or Cue using classical OpenCV methods.
- Complexity: Handling glare, overlapping balls, and dynamic lighting in the 
  billiard clips satisfies the "complexity" and "robustness" rubric criteria.

4. PIPELINE MAPPING (PYTHON TO C++)
--------------------------------------------------------------------------------
- Acquisition: cv::VideoCapture (reads the existing .mp4 clips).
- Enhancement: cv::GaussianBlur (smooths noise and glare).
- Segmentation: 
  - cv::inRange (using existing HSV cloth bounds).
  - cv::bitwise_not (inverts the mask to isolate balls).
  - cv::morphologyEx (cleans up artifacts).
  - cv::findContours (draws bounding boxes/Rect around each ball).
- Feature Extraction: 
  - cv::cvtColor (HSV filtering inside the bounding box).
  - C++ logic to calculate the ratio of white pixels vs. colored pixels.
- Classification: 
  - cv::SimpleBlobDetector (or C++ if/else logic).
  - Rule of thumb: Cue > 80% white; Stripe = 20-50% white; Solid < 10% white.
- Output: cv::rectangle (boxes) + cv::putText (labels).
