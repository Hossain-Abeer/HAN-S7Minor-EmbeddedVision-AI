C. INITIAL DEFECT 1 — RETR_EXTERNAL (THE BLACKOUT)
--------------------------------------------------------------------------------
  First attempt used:
    findContours(mCopy, contours, RETR_EXTERNAL, CHAIN_APPROX_SIMPLE);
  Result: filtered window completely black. Terminal log showed:
    contours=1 accepted=0 rejArea=1 rejCirc=0 rejAspect=0
    area 908090 | bbox 0,0,1280,711

  Cause: The table border/rails form a giant white ring enclosing the
  black cloth. RETR_EXTERNAL only retrieves the outermost contour. 
  Because the balls are enclosed *inside* this giant outer contour (and 
  separated by black cloth), OpenCV treats them as internal hierarchical 
  contours and completely ignores them. The only contour found was the 
  giant frame (area 908090), which was correctly rejected by MAX_BALL_AREA.

  Fix applied:
    findContours(mCopy, contours, RETR_LIST, CHAIN_APPROX_SIMPLE);
  RETR_LIST retrieves all contours without caring about hierarchy.

--------------------------------------------------------------------------------
D. INITIAL DEFECT 2 — MIN_BALL_AREA THRESHOLD (THE SECOND BLACKOUT)
--------------------------------------------------------------------------------
  After fixing RETR_LIST, the filtered window was STILL black. Terminal log:
    contours=25 accepted=0 rejArea=25 rejCirc=0 rejAspect=0
    area 749 | bbox 861,429,33,31
  
  Cause: A ball at this resolution is ~32x32 pixels. The area of a 32px 
  diameter circle is roughly π * 16² ≈ 800. Because DT 0.5 originally 
  set MIN_BALL_AREA = 1500 (a guess based on a different resolution 
  assumption), every single valid ball was being thrown away by the 
  area filter. The table was rejected correctly, but the balls were 
  rejected alongside the noise.

  Fix applied (src/config.h):
    Old: constexpr int MIN_BALL_AREA = 1500;
    New: constexpr int MIN_BALL_AREA = 200;
  Rationale: 200 is high enough to drop the tiny noise specks (areas 
  10-100), but low enough to keep balls (area ~750).

    int nAccepted = 0, nRejectArea = 0, nRejectCirc = 0, nRejectAspect = 0;
    
    for each contour:
      area = contourArea(c);
      if (area < MIN_BALL_AREA || area > MAX_BALL_AREA) { log; reject; }
      
      peri = arcLength(c, true);
      circ = (peri > 0) ? (4.0 * CV_PI * area / (peri * peri)) : 0.0;
      if (circ < MIN_CIRCULARITY) { log; reject; }
      
      Rect bb = boundingRect(c);
      aspect = (float)bb.width / bb.height;
      if (aspect < ASPECT_MIN || aspect > ASPECT_MAX) { log; reject; }
      
      else accept:
        nAccepted++;
        drawContours(filtered, contours, (int)i, Scalar(255), -1);
        rectangle(filtered, bb, Scalar(128), 1);
