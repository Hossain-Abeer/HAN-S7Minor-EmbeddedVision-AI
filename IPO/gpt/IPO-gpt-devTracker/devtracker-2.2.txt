C. INITIAL DEFECT — VARIABLE COLLISION (CAUGHT AND FIXED)
--------------------------------------------------------------------------------
  First build attempt failed with compiler errors:
    "conflicting declaration 'int k'"
    "no match for 'operator||' (operand types are 'cv::MatExpr' and 'cv::MatExpr')"

  Cause: The morphology kernel variable was named `k`:
    Mat k = getStructuringElement(MORPH_RECT, ...);
  But later in the loop, the waitKey return value was also named `k`:
    int k = cv::waitKey(10);
    if (k == 27 || k == 'q') break;

  This caused `k` to shadow the `cv::Mat` with an `int`, and the compiler
  attempted to evaluate `MatExpr || MatExpr` for the exit condition.

  Fix applied (src/main.cpp):
    Renamed the morphology kernel to `morphK`.
