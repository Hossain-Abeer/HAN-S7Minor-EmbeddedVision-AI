C. CODE EXPLANATION
--------------------------------------------------------------------------------
  1. The Rule Order (classify.cpp):
     - `if (wr > RATIO_CUE)`: Highest priority. White ball dominates.
     - `else if (wr > UNCERTAIN_WHITE_HI)`: Extreme glare between 0.60 and 0.65.
     - `else if (wr >= RATIO_STRIPE_LO)`: Stripe range (0.15 to 0.60).
     - `else if (wr >= SOLID_WHITE_LO && ed > EDGE_SOLID_MIN)`: Solid with a 
       visible numeral ring (high edge density).
     - `else`: Catch-all for dark solids (wr < 0.15, ed < 0.10). This prevents 
       the 8-ball and 7-ball from falling into UNCERTAIN.

  2. Color Mapping (main.cpp):
     - CUE    -> White box  (Scalar 255,255,255)
     - SOLID  -> Red box    (Scalar 0,0,255)
     - STRIPE -> Cyan box   (Scalar 255,255,0)
     - UNCERTAIN -> Yellow box (Scalar 0,255,255) with label "?"

  3. Structural Fix (main.cpp):
     - OpenCV draws directly onto the Mat. If `imshow` is called before 
       `rectangle` and `putText`, the window displays the clean frame. 
       Placing `imshow` at the bottom guarantees the UI reflects the drawings.
