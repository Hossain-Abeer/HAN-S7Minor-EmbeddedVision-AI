## FR4 — Concrete Reject Test (Jeroen S2)

**Purpose:** Prove the reject branch fires when input is not a legible numeral.

**Procedure:**
1. Assemble a batch of ≥5 non-numeral crops:
   - Cue ball (blank white ball) — extract from raw clips or use a blank crop from existing data
   - A blank stripe patch (non-numeral ball surface)
   - A heavily blurred crop (Laplacian variance below training `BLUR_THRESHOLD = 75`)
   - An occluded crop (mask area below `MIN_MASK_AREA = 30`)
   - A plain cloth patch (no ball)
2. Save crops to `test_data/reject_batch/`
3. Run `python src/predict.py test_data/reject_batch/`
4. Inspect output CSV: count rows where `status == 'mask_unusable'` or `status == 'imread_failed'`

**Pass criterion:**
- At least 1 row has `status != 'ok'` AND `predicted_label == -1`
- Rows with `status == 'ok'` have valid label in 1..15

**Failure modes and interpretation:**
- 0 rejects → mask threshold too permissive; document; do NOT retune thresholds (would invalidate 3.2)
- Reject fires but with wrong status → check `mask_is_usable()` logic in `mask.py`
- Reject fires with predicted_label != -1 → CSV writer bug in `predict.py`

## TR5 — Timing Procedure

For each of 50 crops drawn from the test set:
1. `t0 = time.perf_counter()`
2. `label, proba, status = predict_crop(pipe, feat_names, path)`
3. `t1 = time.perf_counter()`
4. Record `t1 - t0`

Report:
- `mean_ms`, `median_ms`, `p95_ms`, `max_ms`
- CPU model (`platform.processor()`)
- Python version

**Pass criterion:** median ≤ 1000 ms AND p95 ≤ 1000 ms.

## TR7 — Reproducibility Procedure

1. Record SHA256 of current `models/3.1-final_pipeline.joblib`
2. `cp models/3.1-final_pipeline.joblib models/3.1-final_pipeline.BACKUP.joblib`
3. Re-run `python src/finalize_model.py`
4. Record SHA256 of regenerated joblib
5. Compare `predict_proba` on 5 probe rows (first 5 of `X_train`) between BACKUP and regenerated
6. Compute `max(|proba_backup - proba_new|)`

**Pass criterion:** `max|Δproba| < 1e-9` on 5 probe rows. (Joblib bytes may differ due to pickle timestamp; predictions must be identical.)
