B.10 WHAT A MAGNET MEANS MECHANICALLY
  Under distribution shift:
    - Tree splits become uninformative; feature values drift past
      learned thresholds.
    - Most samples fall into a small number of leaf regions.
    - The bagged ensemble (300 trees) amplifies the majority leaf.
    - One class ends up with a large basin of attraction = a sink.
  Class-12 sink exists because in clips 2-4, class-12 was a
  stripe-with-central-numerals class with centralised projection
  features. Shifted 10, 13 (and 15, 9) produce patterns that hit
  12's training leaves.
  This is not "12 confused with 13". It is "13 has no region; 12
  has a huge region that consumes 13".

SECTION C - TEACHING RECORD (foundations explained during 3.3)
--------------------------------------------------------------------------------

C.1 WHAT ERROR ANALYSIS IS
  After the honest test result is in (3.2), error analysis asks:
    which specific mistakes dominate, and why?
  Not "how do we fix them" - that door is closed (sealed test).
  Just "what does the failure look like when examined closely?"
  Produces: a ranked list of confusions + classifications of each
  class into failure categories.

C.2 WHY RE-PREDICT IS SAFE (SEAL NOT BROKEN)
  The sealed test set rule (3.2) forbids:
    - re-fitting the model on test
    - re-tuning hyperparameters against test
    - making multiple independent prediction passes for selection
  It does NOT forbid:
    - reloading the persisted model
    - calling predict() with the SAME model
  Because 3.1's reload check proved determinism (delta 0.00e+00),
  re-predicting on test with the same joblib produces IDENTICAL
  predictions to 3.2. The seal-integrity assert verifies this.
  If the assert passes (it does), the re-predict is observationally
  equivalent to reading 3.2's output from disk.

C.3 WHAT OFF-DIAGONAL MEANS
  Confusion matrix M: M[i,j] = number of class-i samples predicted
  as class j.
  Diagonal  M[i,i] = correct.
  Off-diagonal M[i,j] i != j = errors from i to j.
  Error analysis ranks cells by M[i,j] descending = worst mistakes
  first.

C.4 SUPPORT vs COUNT
  support_true = total true samples of that class.
  pct_of_true = count / support_true = error rate for that class.
  High pct_of_true with high count = dominant failure.
  High pct_of_true with low count = rare-but-complete failure.
  Both types matter for Section 6.

C.5 KNOWN-PAIR CHECK
  L6, L7 predicted specific pairs would confuse (rotation / overlap).
  Before training, these were HYPOTHESES.
  3.3 tests them against the actual test confusion matrix:
    sum of both directions >= threshold -> CONFIRMED
    below threshold                     -> NOT OBSERVED
  Result: most NOT OBSERVED. The hypotheses were wrong for this
  dataset. Shift collapse overrides feature-design effects.

C.6 STRUCTURAL vs SHIFT-INDUCED vs VAL-ONLY
  STRUCTURAL : F1 = 0 on both val AND test.
               Cross-clip failure. Data/feature ceiling.
  SHIFT-INDUCED : F1 > 0 on val, F1 = 0 on test.
                  Clip-1 specific failure.
  VAL-ONLY       : F1 = 0 on val, F1 > 0 on test.
                   Clip-5 specific failure.
  The three-way split reveals that shift is NOT a single phenomenon.
  Different held-out clips break different classes.

C.7 WHY CLASS-12 IS A MAGNET
  Trace mechanism in a decision tree:
    - In training (clips 2-4), class 12's samples occupy a specific
      region of feature space defined by centralised projections.
    - Under shift, classes 10, 13, 15, 9 shift into that region.
    - Tree leaves favour 12 in that region.
    - Result: 12's leaf gains more traffic from other classes than
      from its own true samples.
  Bagging amplifies this because all 300 trees see the same shifted
  region and agree on 12.

C.8 WHY "SURVIVES" IS RELATIVE, NOT ABSOLUTE
  Class 1 "survives" on F1 0.562. Against SMART target 0.50, that
  is actually a passing score for class 1 alone.
  Class 12 "survives" on F1 0.375. Below 0.50 but non-zero.
  "Survives" here means "F1 > 0", not "passes SMART". Only classes
  1, 2, 6, 11 have F1 >= 0.50 on test.
  For Section 6, use the stricter threshold: classify as "meets
  SMART target" (F1 >= 0.50) vs "below".

C.9 THE CRITICAL FINDING FOR SECTION 6
  L6/L7's pre-training pair predictions were mostly NOT observed.
  Only 3<->4 and the two 12-magnet pairs fired (and 12-magnet pairs
  are shift-driven, not design-driven).
  Implication: the classical feature DESIGN is not the bottleneck.
  Fixing 6/9 or 4/9 would not raise macro-F1 meaningfully.
  The bottleneck is that features measure absolute values that
  respond badly to cross-clip scale drift.
  This justifies Phase 4 as the recovery path: scale-invariant
  learned features, not better handcrafted features.

C.10 WHY THIS MAKES THE REPORT STRONGER, NOT WEAKER
  A report that claimed 0.72 test would be lying.
  A report that states 0.26 test and diagnoses:
    - three structural classes (data-limited)
    - three shift-induced classes (clip-1 specific)
    - three val-only classes (clip-5 specific)
    - dominant class-12 magnet (RF region collapse)
    - L6/L7 hypotheses corrected by evidence
  ... is a stronger report. It demonstrates genuine analysis, not
  result-hiding. Rubric explicitly rewards this.

C.11 WHAT CANNOT BE RECOVERED NOW
  - Test macro-F1 = 0.2607 is set. Cannot raise it.
  - No retuning on test. That would break the seal.
  - No re-split. That would invalidate everything downstream.
  - No re-running 3.2 hoping for a better number.
  Recovery is Section 8's job (narrative), and Phase 4's job
  (better model, next deliverable).

C.12 WHAT CAN BE RECOVERED
  - Honest reporting. Fully addressed by this step's artefacts.
  - Diagnosis. Root cause identified with evidence.
  - Corrected L6/L7 hypotheses.
  - Phase 4 targeting: class 9/10/13 need more data; scale drift
    needs augmentation; 12-magnet needs learned features that do
    not collapse.
  - Code appendix material: error_analysis.py is a strong example
    of post-hoc diagnosis.

C.13 WHAT 3.3 DID NOT DO
  - Did not re-fit the model (seal broken if so).
  - Did not tune anything against test.
  - Did not reclassify classes to flatter the results.
  - Did not hide L6/L7's wrong predictions.
  All four omissions are correct discipline. The report's credibility
