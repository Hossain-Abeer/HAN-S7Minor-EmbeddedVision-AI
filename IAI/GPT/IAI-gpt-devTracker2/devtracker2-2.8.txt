D - TEACHING

D.1 WHY TWO SCALERS PRODUCE IDENTICAL RF RESULTS - LAYER 1
  What each scaler does to a feature:
    Raw value  |  StandardScaler  |  MinMaxScaler
    -----------+------------------+---------------
    0.10       |       -2.5       |      0.00
    0.15       |       -1.2       |      0.17
    0.20       |        0.0       |      0.33
    0.25       |       +1.2       |      0.50
    0.30       |       +2.5       |      1.00
  Ordering preserved column to column. 0.10 stays smallest, 0.30
  stays largest. Both are monotone linear transforms.
  They change the numbers, not the order.

D.2 LAYER 2 - HOW A DECISION TREE SPLITS
  A split is one rule:  feature <= threshold -> left, else right.
  What matters is WHICH ROWS FALL ON EACH SIDE, not the numbers.
  If scaler A and scaler B both preserve ordering, then for any
  threshold t in scaler A there exists a t' in scaler B producing
  the same partition.
  The tree finds the same split either way.
  Extend across all splits, all trees, all 300 trees:
    same splits -> same tree -> same forest -> same predictions
    -> same macro-F1, same accuracy, same std.
  Numerical identity is the only possible outcome.

D.3 LAYER 3 - WHY SVC AND K-NN ARE DIFFERENT
  SVC (RBF) : kernel = exp(-gamma * ||x - x'||^2). Depends on actual
              numeric distances. Scaling changes distances. Different
              scalers -> different boundaries -> different results.
  k-NN      : prediction depends on Euclidean distance to nearest
              neighbours. Scaling changes distances. Different
              scalers -> different neighbour sets -> different
              predictions.
  This is why 9.2 needed StandardScaler: SVC and k-NN would be broken
  without it. RF was never affected either way. One shared pipeline
  is simpler and avoids a class of bugs (scaler outside pipeline,
  double-scaling, refitting across folds).

D.4 WHAT DELTA = 0.000000 ACTUALLY PROVES
  Not a coincidence. Not a rounding artefact.
  Same input, same seed, same folds, monotone-preserving transform.
  Identical scores are a numerical identity, not an empirical
  observation.
  Reporting it is not padding. It closes the loop on Jeroen's S6
  feedback with evidence rather than assertion.
