================================================================================
IAI-GPT ROADMAP - DEVTRACKER
================================================================================

PURPOSE
-------
Sequential build guide for IAI Phase 1. Companion to two existing files:

  IAI-gpt-roadmap-tracker.txt        - overview of all design steps.
  IAI-gpt-designtracker-<step>.txt   - design note per step.

This file answers a different question: what ORDER do I write and run code
in, and how do I know each build step succeeded?

A design step can be complete in the designtracker and still unbuilt here.
Example: designtracker-1.3.1 fully specifies detect_balls(). The function
does not exist on disk until devtracker step 3.1 is done.

HOW TO USE
----------
  - Work top to bottom. Most steps depend on the one above.
  - Before writing any script, open the designtracker note(s) referenced.
  - Tick [x] only after the Verify line passes.
  - If Verify fails, work through the Debug lines before advancing.
  - This file contains NO code. It describes what to write, not how.

LEGEND
------
  [ ]   not started
  [~]   in progress
  [x]   done + verified
  [!]   blocked (dependency unresolved)

TYPE MARKERS
------------
  Type: code          write or modify a script
  Type: decision      choose a value that unblocks downstream work
  Type: manual        human action (sorting, review, reading figures)
  Type: run           execute an existing script and inspect output
  Type: verification  confirm an earlier step produced expected output
  Type: writing       produce report prose
  Type: submission    deliver to instructor or peer team

SECTION 3 - EXTRACTION PIPELINE
================================================================================

Design note 1.2.3 fused four design steps into one runtime script.
Designtracker steps 1.2.3, 1.2.4, 1.3.1, 1.3.2 all execute in this single
script. Frames never touch disk; only crops do.

[ ] 3.1  WRITE extract_crop.py
    Type: code
    Design: designtracker-1.2.3, 1.2.4, 1.3.1, 1.3.2 (read in this order)
    Prereq: 2.3
    Deliver: src/extract_crop.py
    Content: Four functions plus a main loop.
                passes_filter(frame, clip_id, frame_idx) -> bool
                    Laplacian variance for blur; abs-diff for duplicates.
                    Module-level state for last-kept frame.
                detect_balls(frame) -> list of (x, y, w, h)
                    Cloth HSV mask -> invert -> morphology -> contours
                    -> area and circularity filter.
                crop_and_save(frame, regions, clip_id, frame_idx)
                    Padded crop per region; write PNG to unsorted_png/.
                main()
                    Loop clips -> loop frames -> gate -> detect -> crop.
    Key rules:
        - Reset _last_kept_frame at the start of each clip.
        - Rejection log written to REJECT_LOG (CSV). One row per rejected
          frame: reason, clip_id, frame_idx, metric value.
        - Crop filenames: clip{id}_frame{idx}_ball{k}.png
    Verify:  Imports cleanly: python -c "import sys; sys.path.insert(0,
             'src'); import extract_crop"
    Debug:   ImportError -> missing import in config or wrong path.

[ ] 3.2  DRY RUN ON 100 FRAMES OF CLIP 1
    Type: run
    Design: verifies 3.1
    Prereq: 3.1
    Action: Temporarily cap clip loop to clip1, first 100 frames.
            Run: python src/extract_crop.py
    Verify:
        - Script completes without crash
        - unsorted_png\ contains crops
        - rejects.csv has rows
        - RAM stays flat (Task Manager)
        - Open 3-5 crops in Windows Photos: numerals visible?
    Debug (in order):
        0 crops: cloth HSV wrong (re-sample), or MIN_CIRCULARITY too high
                 (lower to 0.6)
        Many crops per frame: HSV range too wide, or MIN_BALL_AREA too low
                 (raise to 3000)
        Blurry crops: BLUR_THRESHOLD too low (raise to 150)
        Duplicate-looking crops: DUP_THRESHOLD too high (lower to 3)
        Cross-clip dupes: last-kept-frame not reset between clips
    Cost:    ~2 minutes.
