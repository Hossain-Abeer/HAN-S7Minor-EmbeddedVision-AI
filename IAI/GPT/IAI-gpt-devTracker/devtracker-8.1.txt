def check_balance([DATASET_CSV], [FIG_DIR])
    [df = pd.read_csv(DATASET_CSV)]
    [overall = value_counts()]
    [pivot = groupby(role, label).unstack()]
    
    [train_df = df[df.role == "train"]]
    [min_c = train_df.label.value_counts().min()]
    [max_c = train_df.label.value_counts().max()]
    [ratio = max_c / max(min_c, 1)]
    
    if [ratio >= 3.0]: [verdict = "SEVERE"]
    elif [ratio >= 1.5]: [verdict = "MODERATE"]
    else: [verdict = "BALANCED"]
    
    [sns.countplot(data=df, x=label, hue=role)]
    [plt.savefig(FIG_DIR / "class_balance.png")]

    PARAMS:
      [DATASET_CSV]   config.DATASET_CSV (492 rows, 26 cols from 7.3)
      [FIG_DIR]       config.FIGURES_DIR
      [SEVERE_RATIO]  3.0  (trigger for class weighting)
      [MODERATE_RATIO]1.5  (trigger for documentation only)

    DESCRIPTION:
      Calculates imbalance strictly on the TRAIN set. Val/test are held out 
      and must remain untouched to preserve the group-by-clip split integrity. 
      Generates a grouped bar chart for visual evidence.

--- 5.1 Phase 1: Data Engineering Pipeline (Produces dataset.csv) ---
- extract_crop.py
  Input: .mp4 video frames (numpy arrays).
  Output: Crops written to disk (unsorted_png/1/...png).
- mask.py
  Input: RGB crops from disk.
  Output: Binary masks (mask_png/1/..._mask.png), where pixels are 0 or 255.
- features.py
  Input: Binary masks.
  Output: features.csv. Converts 2D mask into 1D vector of 23 numerical features.
- assemble.py
  Input: features.csv + splits.csv.
  Output: dataset.csv. Merges features, labels, and roles into a single tabular file.

--- 5.2 Phase 2: Classical ML Pipeline (Consumes dataset.csv) ---
Data Loader (pandas)
  Input: dataset.csv.
  Output: 2D numpy array X (shape [N, 18]), 1D array y (shape [N,]).
sklearn.pipeline.Pipeline
  Step 1: StandardScaler
    Input: X (raw feature values).
    Output: X_scaled (mean=0, variance=1).
  Step 2: Classifier (KNN / SVM / RF)
    Input: X_scaled, y.
    Output: y_pred (array of predicted labels 1-15).

Key Boundary: mask.py is strictly upstream. The ML pipeline never sees masks 
or images; it only sees the dataset.csv numerical table.

--- 5.3 Algorithm Fundamentals ---
KNN (K-Nearest Neighbors)
  Fundamental (k): Number of nearest neighbors. Distance metric usually Euclidean.
  Prediction: Majority vote among the k closest training samples.
  Input: X_train (Shape: [255, 18]), y_train (Shape: [255,]).
  Output: y_pred (Shape: [M,]). Consumes arrays from Pipeline.

SVM (Support Vector Machine)
  Fundamental (C, gamma): C = penalty (regularization). gamma = kernel width.
  Function: Finds hyperplane maximizing margin between classes.
  Input: X_train (Shape: [255, 18]), y_train (Shape: [255,]).
  Output: y_pred (Shape: [M,]). Also decision_function (Shape: [M, 15]). 

RF (Random Forest)
  Fundamental (n_estimators, max_features): n_estimators = number of trees. 
  max_features = features considered for best split. Uses Gini impurity.
  Input: X_train (Shape: [255, 18]), y_train (Shape: [255,]).
  Output: y_pred (Shape: [M,]). Also predict_proba (Shape: [M, 15]).
