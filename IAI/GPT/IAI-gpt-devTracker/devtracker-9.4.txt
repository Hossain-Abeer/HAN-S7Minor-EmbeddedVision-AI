================================================================================
1. ESSENCE
================================================================================

WHAT IT IS
  A single command run. No files written, no data loaded, no figures.
  Console output only, ephemeral.

WHY IT EXISTS
  Writing the factory (9.3) is not proof it works. The smoke test block
  inside src/pipeline.py sits under if __name__ == "__main__", which
  never runs when the file is imported by Phase 2. Running the file
  directly is the only way to exercise it.

  This step is a stop-and-check between 9.3 and Phase 2. If step names
  are typo'd, Phase 2's grid search fails with a ValueError that points
  at the param grid, not at the typo. 9.4 catches the typo in ~2 seconds.

WHY DummyClassifier
  Cheapest sklearn classifier. fit() is a no-op. It cannot fail for data
  reasons, so any 9.4 failure is guaranteed structural. Isolates assembly
  from behaviour.

WHAT 9.4 DOES NOT VERIFY
  That the Pipeline fits real data. That is Phase 2's job. 9.4 is
  assembly-only.

8. RECOMMENDATIONS
================================================================================

a. What to expect
   - No CSV, no figure, no log (unless Tee used).
   - Console output only, ephemeral.
   - Exit code 0 on success.
   - Runtime ~2 seconds.

b. Do NOT skip 9.4
   Phase 2 will import the factory and call build_pipeline(SVC()). If
   a step name was typo'd ("scalar", "classifier"), Phase 2's
   param_grid = {"clf__C": ...} fails with ValueError: Invalid
   parameter 'clf' for estimator Pipeline. That error points at the
   grid, not at the typo. 9.4 catches it in 2 seconds; Phase 2 catches
   it after 15 minutes of confusion.

c. Do NOT extend 9.4 into a real fit
   Resisting pipe.fit(X_train, y_train) here is the point. Fitting
   requires dataset_clean.csv, feature columns, label extraction -- all
   Phase 2 concerns. Keep 9.4 structural only. Blurring the boundary
   between "factory works" and "factory + data works" makes debugging
   harder.

d. Rubric relevance
   None directly. 9.4 does not appear in any report section. It exists
   only to prevent Phase 2 silent failures.

e. Report surface
   None. Do not mention 9.4 in Preliminary ML §3 or Full ML §6. The
   report only needs 9.3's sentence ("preprocessing and classification
   are encapsulated in an sklearn Pipeline so that the scaler refits
   inside each CV fold").
