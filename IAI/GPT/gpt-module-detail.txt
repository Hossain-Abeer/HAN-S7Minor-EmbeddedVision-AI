IAI / EVML-EVD3 - MODULE UNDERSTANDING

================================================================================
1. OVERVIEW
================================================================================

IAI (EVML-EVD3) is a hands-on workshop-style module teaching machine learning and
deep learning for (embedded) computer vision. It is part of the minor Embedded
System & Vision with Deep & Machine Learning.

Core philosophy:
- No single algorithm works for every problem -> you try multiple approaches.
- Data matters more than algorithms (but good features/algorithms still matter).
- Iterative workflow: collect -> explore -> engineer -> train -> validate ->
  deploy -> test -> reflect.

Structure: Two mini-projects (ML in Term 1, DL in Term 2), each 80% report + 20%
quizzes. Teams of 2-3. Final deliverables: report (Word), code (zip), deployment
video.

Tools: Python 3.11, OpenCV, scikit-learn, TensorFlow/Keras, PyTorch (ViT), Git,
VS Code / Colab.

Books: Geron (3rd ed.), Kaehler & Bradski (Learning OpenCV 3).

3. OBJECTIVES OF THE EXERCISES
================================================================================

Exercise Type                 | Objective
------------------------------|-----------------------------------------------
OpenCV tutorials              | Master image I/O, colour spaces, transforms,
                              | drawing, contours.
Segmentation & feature        | Convert images -> numerical feature vectors
extraction                    | (shape, colour, texture, Hu moments, ORB).
EDA scripts                   | Visualise class balance, feature distributions,
                              | correlations; assess feature quality.
Classification scripts        | Train SVM, k-NN, decision trees; use pipelines;
                              | grid search; cross-validate.
Performance scripts           | Build confusion matrices, classification
                              | reports, learning curves; diagnose bias/
                              | variance.
Unsupervised scripts          | Cluster with K-means, GMM, DBSCAN; reduce
                              | dimensions with PCA/t-SNE; detect anomalies.
Regression scripts            | Fit linear/polynomial/logistic models;
                              | regularise; evaluate with MSE/R2.
DL quickstart                 | Build, compile, train, evaluate a shallow
                              | neural net on Fashion-MNIST.
CNN demos                     | Visualise convolution, pooling, feature maps;
                              | understand kernel effects.
TensorBoard                   | Monitor training, compare runs, visualise
                              | graphs.
Augmentation                  | Artificially expand dataset; understand
                              | geometric + photometric transforms.
Transfer learning             | Fine-tune pretrained models (MobileNet,
                              | ResNet, ViT) on your own data.
Hyperparameter tuning         | Use Keras Tuner / GridSearchCV to optimise
                              | architecture and LR.
Deployment                    | Export to TFLite, benchmark inference, deploy
                              | to edge/web/Docker.

7. PROPOSED ROADMAP FOR YOU
================================================================================

Sequence of Events
------------------

1. Phase 0 - Setup (now):
   - Install Python 3.11, create evml_env, pip install -r requirements.txt.
   - Set EVML_DATA env var.
   - Verify: import cv2, sklearn, tensorflow.
   - Git clone repo, set up .gitignore.
   - Form team (2-3), choose project path (gesture / object / EVML integration).

2. Weeks 36-38 - Learn & collect:
   - Attend all classes, take quizzes.
   - Run all example scripts (opencv_tutorial_01/02, acquire.py, segment.py,
     extract.py, fetch_data.py, explore.py).
   - Start data collection early with a protocol (vary angle, distance,
     lighting, subject).
   - Build feature extraction pipeline; explore features.

3. Weeks 39-40 - Model & preliminary report:
   - Run supervised_01-06, performance_01-03.
   - Compare classifiers (SVM, k-NN, trees, forests).
   - Write preliminary report (sections 1-3); submit week 40.
   - Collect peer feedback; review another team's report.

4. Weeks 41-45 - Full ML report:
   - Finalise model, tune hyperparameters, cross-validate.
   - Deploy (Flask/Docker/edge) and test against requirements.
   - Write full report; submit week 45.

5. Weeks 46-51 - DL project:
   - Run tf_quickstart, tf_tensor_board, convolution_demo, pooling_demo.
   - Build custom CNN + transfer learning model (MobileNet/ResNet/ViT).
   - Augment data (augmentor_example, tf_data_generators).
   - Tune with Keras Tuner / GridSearchCV.
   - Deploy (TFLite), benchmark, document.

6. Weeks 1-2.9 - DL report:
   - Compare custom CNN vs transfer learning vs ML baseline.
   - Visualise layers (Grad-CAM, feature maps).
   - Submit DL report week 2.9.

Additional Advice
-----------------

- Start data collection in week 36-37. It is the biggest bottleneck.
- Use Git from day 1. Commit often.
- Document decisions (why SVM over k-NN, why this LR, etc.) - this is what
  separates 7s from 9s.
- Run every script in scripts/ - they are your reference implementations.
- Use the guides (support material/guides/) - especially
  3_ml_classical_cv.md and 4_dl_cnn.md.
- Take quizzes seriously - 20% of each grade.
- Peer review is valuable - give sharp, constructive feedback; learn from
  others.
- Deploy early - don't leave deployment to the last week.
- Compare ML vs DL - the DL report requires this.
- Set random seeds - reproducibility.
- Watch for data leakage - split before scaling.
- Use pipelines - sklearn Pipeline prevents leakage and simplifies code.
- Read the templates carefully - acceptance criteria are your checklist.
- Attend all classes - quizzes are at the start; no re-entry.
- Use Colab if your laptop lacks GPU.
- Keep a log - experiments, results, decisions.
- Ask for help early - stuck >3 days? Ask instructor/peers.
