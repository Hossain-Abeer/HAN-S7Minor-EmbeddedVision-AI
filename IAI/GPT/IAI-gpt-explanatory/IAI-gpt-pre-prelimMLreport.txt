File: src/constants.py
Purpose: Facts about the world. Not program parameters (those in config).

NUM_CLASSES = 15
CLASS_IDS   = [1..15]

# Cloth colour locked at 2.1 (from clothColor_noAspectRatio.png,
# sampled via clothColor_sampler.py, widened per widening_rules.md):
CLOTH_H_LO = 80      # Hue
CLOTH_H_HI = 100
CLOTH_S_LO = 100     # Saturation
CLOTH_S_HI = 255
CLOTH_V_LO = 30      # Value (brightness)
CLOTH_V_HI = 255

# Data targets:
MIN_CROPS_PER_CLASS = 50
TARGET_TOTAL_CROPS  = 750

WHY THESE HSV BOUNDS
  Cloth is teal (H~90). Raw pixel sample from the dark shadow region:
  H(89-92), S(163-255), V(39-77).
  Widening rules (widening_rules.md):
    H: center 90, +/- 10  -> 80-100. Rejects wood rails and ball hues.
    S: floor 100          -> rejects white cue ball (S~0) and white
                             stripe bands while keeping cloth (S>160).
    V: floor 30           -> captures shadow (V=39) but stops before
                             pure black (V=0), which would include the
                             8-ball and pockets.

EXTRACTION GROUP (1.2.3 + 1.2.4)
  N_CLIPS          = 5
  FRAME_STRIDE     = 1     # every frame (motion gate does the filtering)
  BLUR_THRESHOLD   = 75.0  # Laplacian variance floor
  DUP_THRESHOLD    = 3.0   # mean abs pixel diff floor to last kept
  DUP_RESIZE_W     = 160   # downsample width before diff
  DUP_RESIZE_H     = 90    # downsample height before diff
  MOTION_THRESHOLD = 4.0   # motion state machine threshold

DETECTION GROUP (1.3.1)
  MIN_BALL_AREA    = 800   # px^2
  MAX_BALL_AREA    = 6000  # px^2
  MIN_CIRCULARITY  = 0.7   # 4*pi*area / perimeter^2
  DET_MORPH_KERNEL = 5
  DET_MORPH_OPEN   = 2
  DET_MORPH_CLOSE  = 2

CROP GROUP (1.3.2)
  PADDING_PCT      = 0.15  # 15% margin on all sides

MASK GROUP (1.5.1)
  MASK_S_MAX         = 60    # max saturation for "white" numeral pixels
  MASK_V_MIN         = 180   # min brightness for "white" numeral pixels
  MASK_MORPH_KERNEL  = 3
  MASK_MORPH_OPEN    = 1
  MASK_MORPH_CLOSE   = 0     # CRITICAL: must stay 0
  MIN_MASK_AREA      = 30    # pixels

FEATURES GROUP (1.5.2)
  USE_FEATURES      = [hole_count, connected_component_count,
                       blob_area_ratio, hole_area_ratio, hole_aspect,
                       hole_centroid, projections]
  PROJ_BINS         = 8
  KEEP_HU_MOMENTS   = False
  MIN_HOLE_AREA_PX  = 5

WHY MOTION GATE INSTEAD OF STRIDE
  Stride-based extraction (original design) wasted frames on static
  aiming phases and motion blur. Replaced with a state machine that
  only triggers extraction after the scene has been still for >=3
  consecutive frames.
  Consequence: FRAME_STRIDE=1 (check every frame), motion gate does
  the filtering. Yield is governed by shot-settle count, not stride.

WHY MASK_MORPH_CLOSE = 0
  MORPH_CLOSE (dilate then erode) FILLS holes. Numerals 0/6/8/9 are
  defined by their holes. Closing would destroy the very feature that
  1.5.2 relies on. OPEN (erode then dilate) is safe - removes specks.

WHY PADDING = 15%
  Smallest padding that guarantees full ball + antialiased edge + a
  thin cloth ring. The cloth ring is USEFUL: downstream masking at
  1.5.1 uses the same CLOTH_* HSV range to strip it out, leaving a
  clean ball-only region.

6. CODEBASE INVENTORY
================================================================================

All .py files in src/. Each entry: filename, purpose, key functions,
which tracker step it implements.

src/config.py           (2.3b)
  Parameters. See Section 5.

src/constants.py        (2.3a)
  Domain facts. See Section 4.

src/clothColor_sampler.py  (2.1 tool)
  Interactive OpenCV GUI. Left-click samples a pixel; drag samples a
  rectangle and prints H/S/V min/max. Used to derive CLOTH_* bounds.
  One-shot tool, not part of pipeline.

src/widening_rules.md   (2.1 doc)
  Documents how raw HSV bounds were widened to final values.

src/extract_crop.py     (3.1)
  FUSED EXTRACTION SCRIPT. Motion-gated. Combines 1.2.3 + 1.2.4 +
  1.3.1 + 1.3.2 in one loop.
  Key functions:
    main()                  - loops over clips, state machine for
                              motion gate, calls passes_filter then
                              detect_balls then crop_and_save.
    passes_filter(frame, clip_id, frame_idx)
                            - blur gate (Laplacian variance) + duplicate
                              gate (mean abs diff to last kept).
    detect_balls(frame)     - cloth HSV mask inverted, morphology,
                              contours, area+circularity filter.
                              Uses RETR_LIST (not RETR_EXTERNAL).
    crop_and_save(frame, regions, clip_id, frame_idx)
                            - padded crop, writes to CROP_ROOT.
    log_reject(reason, clip_id, frame_idx, metric_value)
                            - appends to REJECT_LOG.
  Output: unsorted_png\clip{id}_frame{idx:06d}_ball{k}.png
  Env vars for dry run: EVML_DRY_RUN_CLIPS, EVML_DRY_RUN_FRAMES.

src/debug_mask.py       (3.1 diagnostic)
  Saves debug_mask.png + prints contour stats. One-shot diagnostic.

src/extract_dry_run.ps1 (3.2 tool)
  PowerShell wrapper for dry run.

src/keyboard_sorter.py  (4.2 tool)
  Tkinter GUI. Displays one crop at a time, user presses a key to
  move it to the matching class folder or delete it.
  Key map:
    1-9       -> classes 1-9
    q,w,e     -> classes 10,11,12
    a,s,d     -> classes 13,14,15
    x         -> DELETE
    space     -> SKIP
    ESC       -> QUIT
  Uses shutil.move (preserves filenames).

src/audit.py            (4.3)
  Counts PNGs per class folder under CROP_ROOT, prints table, flags
  SHORT classes (<MIN_CROPS_PER_CLASS). Tee stdout to log.
  Key functions:
    count_per_class(crop_root, class_ids)
    report_counts(counts, min_per_class)
    _tee_stdout(log_path)

src/split.py            (5.1)
  Group-by-clip split. Deterministic. No random seed.
  Key functions:
    scan_crops(crop_root, class_ids)      -> (rel_path, label, clip_id)
    score_clips_by_coverage(records)      -> {clip: (covered, min_count)}
    assign_roles(scores)                  -> {clip: role}
    write_splits_csv(records, roles, out) -> splits.csv
    coverage_matrix(records)              -> diagnostic
  Assignment rule: rank 0 -> val, rank 1 -> test, ranks 2+ -> train.
  Tie-break: clip_id ascending.
  Output: splits.csv with columns filename, role.

src/verify_split.py     (5.3)
  Reads splits.csv, prints matrix, checks floors.
  HARD_FLOOR_TRAIN   = 5
  HARD_FLOOR_VALTEST = 1
  SOFT_TARGET_VALTEST = 3
  Key functions: _tee_stdout, load_splits, class_from_filename,
                 build_matrix, print_matrix, check_floors,
                 report_failures, main.

src/mask.py             (6.1)
  Extracts numeral-region mask per crop. HSV high-V low-S threshold,
  intersect with non-cloth, morphology OPEN only.
  Key functions:
    extract_numeral_mask(crop_bgr)
    mask_is_usable(mask)
    log_reject(class_id, filename, n_pixels)
    build_masks(crop_root, mask_root, class_ids, dry_run_crops=0)
  Output: mask_png\<class>\<crop>_mask.png
  Reject log: MASK_REJECT_LOG (rejects_mask.csv).
  Env var: EVML_DRY_RUN_CROPS.

src/mask_dry_run.ps1    (6.2 tool)
  PowerShell wrapper (sets EVML_DRY_RUN_CROPS=20).

src/mask_diagnose_thresholds.py  (7.2 diagnostic, named .ps1 in file

  Tests six (V_MIN, S_MAX) threshold pairs across five representative

src/mask_diagnostic_5x5.ps1  (7.2 diagnostic)
  Tests whether MORPH_CLOSE=5x5 would recover holes. One-liner Python

src/features.py         (7.1)
  Feature extraction from masks. 23 features in 7 categories.
  Key functions:
    largest_blob(mask)              - largest non-background CC
    find_holes(blob_mask, min_area_px) - background CCs not touching

    projections_binned(blob_mask, n_bins, blob_area)

    features_from_mask(mask, use_features, proj_bins, keep_hu,

9. DESIGN DECISIONS LEDGER - WHY EACH CHOICE
================================================================================

DATA SOURCE
  Screen recording of billiard game (not physical camera).
  Reason: approved by module lead; avoids rig setup; deterministic
  (same game build = same cloth, lighting, resolution across clips).
  Cost: 720p-effective render, hence the 7.2 semantic failure.

MOTION GATE OVER STRIDE
  State machine fires extraction only after scene still for >=3 frames.
  Reason: eliminates aiming-phase frames and motion blur without
  manual trim. Yield becomes shot-count-proportional, not stride-
  proportional.

PADDING 15%
  Smallest padding that guarantees full ball + antialiased edge + a
  useful cloth ring. Cloth ring is stripped downstream.

MASK_MORPH_CLOSE = 0
  Closing fills holes. Must not do that for numerals 0/6/8/9.

CROP-LEVEL BLUR FILTER: SKIPPED
  Frame-level blur filter at 3.1 handles it. Manual audit at 4.2
  removes residual bad crops. Second threshold would need second
  justification.

CROP FORMAT: PNG
  Lossless. Small file size at ball radius. Matches course scripts.

SORTING: SCRIPTED CROP + MANUAL KEYBOARD GUI
  Scripted extraction + cropping (reproducible, unbiased). Manual
  keyboard sort (Tkinter GUI) - forces visual inspection of every
  crop, which is the audit anyway. Rejected: drag-and-drop in
  Explorer (slow), OCR-assisted pre-sort (circular, and CnOCR broke
  env).

SPLIT: GROUP-BY-CLIP
  Frames 5 apart within a clip are near-identical. Group-by-clip
  prevents leakage. Rejected: file-level random (leaks frames across
  roles).

SPLIT RATIO: 3/1/1 = 60/20/20
  With 5 clips, only partition. Rejected 2/1/2 (val too small),
  4/1/0 (no test), 2/1/1 (one clip homeless).

SPLIT ASSIGNMENT: BEST COVERAGE -> VAL, NEXT -> TEST, REST -> TRAIN
  Val looked at repeatedly during training; needs most coverage.
  Deterministic (no random seed).

FEATURE CHOICE (23 engineered -> 15 retained)
  Engineered: hole geometry + projections. See Section 6 (features.py).
  Rejected: raw pixels (curse of dimensionality), colour histograms
  (weak signal - solids share colour with stripes), Hu moments on ball
  outline (destroys rotation info needed for 6/9), ORB (weak on small
  low-contrast numerals).

CLEANING: IQR K=1.5 ON TRAIN ONLY, CLIP NOT REMOVE
  Thresholds from train -> applied to all. Rejected: z-score
  (non-normal features). Rejected: remove (breaks class balance).
  Excluded from cleaning:
    - discrete features (IQR=0 kills minority values)
    - projection bins (bounded sum-to-1 breaks under clip)
  Only blob_area_ratio is cleaned.

SCALING: StandardScaler FIT ON TRAIN ONLY
  SVM RBF and k-NN are distance-based. RF is scale-invariant but
  shared pipeline keeps uniformity. Rejected: MinMax (sensitive to
  tails), Robust (9.1 already handled tails).

PIPELINE: [StandardScaler, Classifier]
  Refits per CV fold. Prevents leakage. Rejected: pre-scaled
  dataset outside pipeline (leaks). Cleaning kept OUTSIDE pipeline
  (accepted simplification - marginal benefit, real complexity cost).

CLASS IMBALANCE: class_weight='balanced' IN PHASE 2
  Not resampling. Weighting preserves data integrity. Rejected:
  resampling (distorts distribution), document-only (weakest).

TEST/TRAIN MODEL SPLIT
  Test set held out. Looked at ONCE. Train only for fit. Val for
  tuning. No exceptions.

AUGMENTATION (Phase 4, planned)
  Needed: brightness/contrast/perspective, NOT blanket rotation (6/9
  ambiguity requires careful rotation design). Aggressive on minority
  classes (10, 2, 7, 13, 5).

10. LIMITATIONS AND DEVIATIONS LEDGER
================================================================================

Every known limitation. Each must appear in Preliminary ML section 3
(or Full ML section 8 / DL section 6 if relevant).

L1  DATASET SIZE - 505 CROPS / 15 CLASSES
    Average ~33/class. Only C1 (82) exceeds 50/class floor.
    14/15 classes are SHORT vs design target of 50/class.
    Cause: motion-gated extraction yields ~1 crop per ball per shot.
    Mitigated by: assessed as functional-pipeline bar (Jeroen Veen
    prioritises working end-to-end over dataset size). Documented.

L2  CLASS IMBALANCE - 8.6:1 TRAIN
    Train max=43 (C1), min=5 (C5, C10). Verdict SEVERE.
    Mitigated by: class_weight='balanced' in Phase 2.
    Consequence: minority classes will still underperform. Document.

L3  TEST THINNESS - C7 = 1 CROP
    Class 7 test set is 1 crop. Test accuracy for class 7 will be
    0% or 100% - statistically meaningless.
    Not fixable by re-recording (same 4-6 h cost). Documented as
    known limitation.

L4  VAL THINNESS - C10 = 2 CROPS
    Class 10 val set is 2 crops. Val accuracy for class 10 noisy.
    Lower risk than L3. Documented.

L5  5 DEAD FEATURES (7.2 SEMANTIC FAILURE)
    hole_count, hole_area_ratio, hole_aspect, hole_centroid_dx,
    hole_centroid_dy are constant zero across all 492 samples.
    Cause: 720p-effective source resolution fragments the numeral
    patch; numerals become notches, not enclosed holes.
    Status: DOCUMENTED, not fixable. Phase 4 CNN recovers via learned
    features. This failure IS a report finding - establishes the
    classical ceiling the CNN is compared against.

L6  6/9 ROTATION AMBIGUITY
    A 6 rotated 180deg is visually identical to a 9. Projections are
    rotation-invariant; hole features dead. Classification between
    6 and 9 is UNACHIEVABLE with current classical features regardless
    of volume. Colour as a 6/9 tie-break was considered but not
    implemented.
    Phase 4 CNN recovers this via non-rotation-invariant learned
    features + careful augmentation. Key narrative for DL report.

L7  FEATURE OVERLAP - 4/9, 11/1, 2/5
    These class pairs overlap in silhouette projection space. Volume
    will not fix it. Classical ceiling.

L8  492 vs 505 ROWS
    13 crops lost between 4.4 (505) and 7.3 (492) due to mask
    rejection at 6.1. Documented.

L9  PROJECTION SUM-TO-1 INVARIANT BROKEN AFTER SCALING
    The 16 projection bins sum to 1 in raw form. Post-StandardScaler,
    they do not. The classifier is fine (treats features
    independently). The interpretation is not (any figure displaying
    scaled projections must note this). Documented in 9.2.

L10 DISCRETE FEATURES BECOME NON-INTEGER AFTER SCALING
    connected_component_count raw values {1..8} become continuous
    floats. Mathematically valid. Document.

L11 FOUR ROWS EXCEED |5| AFTER SCALING
    proj_x_0 (6.52 train, 6.81 test), proj_y_5 (5.79 test),
    proj_y_6 (6.75 train). Legitimate sparse signal amplified by
    division by small std. Not outlier contamination. Accepted.
    Documented in 9.2.

L12 POSITIONAL SHORTCUT RISK
    Crops may correlate numeral with position if all clips start at
    same gameplay phase. Mitigated at recording time by staggering
    start offsets (need to verify this was actually applied - flag
    for 10.1). Feature selection at 8.3 partially mitigates (proj
    bins carry position signal). Augmentation at Phase 4 will fully
    break it.

L13 CNOOCR / EXTERNAL OCR NOT AVAILABLE
    Cannot use pretrained digit recognisers (broke env; also
    circular - solves the module's own OCR task during data prep).
    Sorting was fully manual.

L14 POOL BALL CONVENTION ASSUMED
    Standard pool: 1-8 solid, 9-15 striped, colour-number mapping
    follows convention. Not verified against game build. Assumed.
    Fine for classification task; note if report needs to justify.

L15 SCREEN RECORDING ≠ PHYSICAL CAMERA
    Angle, distance, lighting, background are constants, not axes.
    Dataset does not reflect real deployment variation. Augmentation
    must compensate. Explicit in §3.

15. GLOSSARY OF PROJECT-SPECIFIC TERMS
================================================================================

Term                 | Meaning
---------------------|------------------------------------------------------
Motion gate          | State machine in extract_crop.py that only triggers
                     | extraction after >=3 consecutive still frames.
                     | Yields ~1 crop per ball per shot-settle event.
Fused stage          | build via extract_crop.py: extraction+filter+
                     | detection+crop in one loop. Avoids disk dump of
                     | intermediate frames.
Cloth ring           | The 15% margin around each crop. Useful for
                     | downstream masking (strip it out to get ball-only).
Retained feature     | One of the 15 features that survived 8.3's
                     | correlation filter. Written to
                     | retained_features_correlations.txt.
Dead feature         | One of the 5 features constant zero across all
                     | samples (7.2 failure). Result of resolution ceiling.
Semantic failure     | 7.2's finding: features computed mechanically but
                     | return no information.
Feature overlap      | Class pairs (4/9, 11/1, 2/5) whose silhouettes are
                     | too similar in projection space. Unfixable by volume.
Positional shortcut  | Risk that model learns numeral->position rather
                     | than numeral->shape. Mitigated by staggering
                     | recording start offsets + feature selection +
                     | augmentation.
Tee                  | Python helper in most scripts: sys.stdout is redirected
                     | to both the console and a log file. Implemented
                     | via a small _Tee class.
Hard floor           | In split.py: train >= 5, val/test >= 1 per class.
                     | FAILURE = split is broken.
Soft miss            | In split.py: val/test < 3 per class. NON-BLOCKING.
                     | Documented limitation.
Two threads          | Thread A = teaching. Thread B = validation.
                     | This file supports Thread B handoff.
Designtracker        | "Why" document per step. Extends to Full ML + DL.
Devtracker           | "What was done" document per step. Stops at 10.x.
Phase 2              | Classical ML model training (SVM, k-NN, RF).
                     | Begins after Prelim ML submission.
Phase 3              | Full ML model report + deployment.
Phase 4              | Custom CNN + transfer learning (DL report).
Phase 5              | DL deployment + comparison.
Phase 6              | Final DL report.
SMART                | Specific, Measurable, Achievable, Relevant, Time-
                     | bound. Used in Section 2 problem statement.
F1, precision, recall| Phase 2 evaluation metrics. Also confusion matrix.
