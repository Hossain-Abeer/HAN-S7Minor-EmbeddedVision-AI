--------------------------------------------------------------------------------
KEY LESSONS / GOTCHAS
--------------------------------------------------------------------------------

1. py install syntax:
   - WRONG:  py install 3.11 C:\dev\python311
   - RIGHT:  py install 3.11 --target C:\dev\python311

2. py install --target does NOT register with the py launcher:
   - py -0p will not show it.
   - py -3.11 will not work.
   - Use `python` directly instead.

3. py install --target is a MINIMAL bundle:
   - Provides python.exe only.
   - Does NOT provide Scripts\ folder.
   - Does NOT provide pip.exe.
   - This is fine for our use case: pip comes bundled inside the venv
     (created via `python -m venv`), not needed at the base level.

4. Microsoft Store Python stubs:
   - Ship with Windows, live in %LOCALAPPDATA%\Microsoft\WindowsApps\.
   - Sit high on PATH, intercept python/python3/pythonw.
   - Must be disabled via App Execution Aliases, not deleted.

5. py uninstall auto-reinstall quirk:
   - After uninstalling a version, the python shim may re-trigger the
     manager's auto-download on next invocation.
   - Mitigation: install the replacement version promptly, or run
     `py uninstall --purge <version>` to remove shims.

6. Long path support (>260 chars):
   - Needed for TensorFlow, PyTorch, and deep nested package trees.
   - Enable via py manager prompt or Group Policy.
   - Requires reboot to take effect.

7. Username in paths breaks cross-laptop sync:
   - Default py install location: C:\Users\<username>\AppData\Local\Python\
   - Fix: use --target to install to a username-free path like
     C:\dev\python311\.

8. Custom target vs py launcher registry:
   - py launcher uses its own registry config.
   - Custom targets are not registered automatically.
   - Workaround: rely on PATH instead of py.

9. uv-managed Python:
   - uv (Astral) maintains its own Python installs under
     C:\Users\<user>\AppData\Roaming\uv\python\.
   - These are not the same as py-managed installs.
   - Safe to leave alone if unused by course.
